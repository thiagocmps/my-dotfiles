# my-dotfiles
Criado separar as as configurações de alguns programas gerais do meu repositório 'aperture-interfaces-dotfiles', que tem um foco muito mais para um tema de hyprland do que uma 'toolbox', se é que eu posso chamar assim.

# Programas que utilizo (ou pretendo utilizar)
1. Neovim - IDE/Editor de texto padrão
2. bash - Minhas configurações bash favoritas estão aqui (aliases, variáveis de ambiente, etc)
3. Ranger - gerenciador de arquivos que utilizo junto do Neovim 
4. ble.sh - Autocomplete e gerenciador de cores para bash, honestamente uso só pra colorir meu terminal
